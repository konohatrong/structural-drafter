# General-Notes Drawing Instruction (A3)

This file explains how to draw the general-notes sheet of a structural set, whatever the material, e.g. `…-ST-1001`. The layout rules (sizes, anatomy, wording, tables, engine) apply to every set; the worked example is the concrete notes. §4.3 lists what a **concrete** notes sheet must carry; for steel, see `docs/steel/STEEL_DETAILING_INSTRUCTION.md` S1 and S9 (the SRT-ST-1001 sheet is the example).

**Current sheets: issued F-A "ISSUED FOR USE" (03/10/2026)**, `STR-ST-1001-F-A … 1003-F-A`, *General Notes (1 – 3) – Structural Concrete* (`standard_drawings/REGISTER.md`). They were developed as review print B, so the "Rev B" rules of §0 are the method of the issued sheets.
- Generator: `jobs/standard_set/gn_notes.py` (model-space sheets from blocks).
- Build: `python build.py gn`; plot (from PowerShell): `python plot.py gn`.
- Output: `jobs/standard_set/out/STR-ST-1001_General_Notes_Concrete_A3_RevA.*`.

**Review print A** (`STR-ST-1001-D-A`, one sheet, K = 0.625) is frozen in `jobs/general_notes/rev_A/`, generated by `jobs/general_notes/build_gn.py`. Sections 1 – 10 below describe the Rev A method. **Section 0 gives the Rev B rules that replace or extend it.**

**Read with:**
- `DRAWING_STANDARD_EIT-011006-19.md`, whose §19 office conventions are the "general drawing rule" below;
- `ANNOTATION_ALIGNMENT_GUIDE.md`;
- `docs/concrete/GENERAL_NOTES_STRUCTURAL_CONCRETE.md`, the source of the concrete note wording;
- `SPEC_RC_DESIGN_EIT-011008-21.md` and `SPEC_CONCRETE_EIT-011014-19.md`, the clause digests behind the citations.

## 1. The rule in one line

> **Everything on a general-notes sheet is the general drawing rule × K, where K = 1.25 / 2.00 = 0.625.**

- **What scales:** all text and every annotation dimension, gap and symbol.
- **What doesn't:** the sheet frame, zone grid and title strip stay at the set standard, so every sheet in the set looks the same. Pen weights stay on the standard pen table, because the plot pens (0.13–0.70) are set-wide and cannot go smaller.

A notes sheet is read at arm's length and holds far more text than a drawing sheet. Scaling everything together keeps the sheet's internal proportions identical to our other sheets, just smaller.

**Legibility check:** 1.25 mm is below EIT 011006-19's smallest lettering size (2.5 mm on A2, about 1.8 mm on A3 originals). It is acceptable only on notes sheets. Check a printed A3 copy before each issue and never reduce the print.

## 3. Sheet anatomy

```
┌───────────────────────────────────────────────────────────────────────┬──────────┐
│ 1. GENERAL          │ 5.5 … [COLUMN TIES]     │ 8.2 … [FORM REMOVAL]   │  NOTES   │
│ 2. DESIGN BASIS     │ 6. DEVELOPMENT, SPLICES │ 8.4 [TOLERANCES]       │  STATUS  │
│ 3. CONCRETE         │   [LAP & ANCHORAGE]     │ 9. PLACING … 13.       │  KEY PLAN│
│   [CONCRETE SCHED.] │ 7. COVER                │ ABBREVIATIONS          │  REVS    │
│   [SULFATE]         │   [COVER BY ELEMENT]    │                        │  …       │
│ 4. TESTING          │   [RECOMMENDED – ENV.]  │                        │  TITLE   │
│ 5. REINFORCEMENT    │ 8. FORMWORK …           │                        │  STRIP   │
│   [HOOKS & BENDS]   ├────────────────────────────────────────────────┤  70 mm   │
│ (column 1 runs to   │ TYPICAL DETAILS (grey rule above)              │ (not     │
│  the frame)         │ [cover – beam 1:10] [std. hooks] [lap stagger] │ scaled)  │
└─────────────────────┴────────────────────────────────────────────────┴──────────┘
```

**Note columns:**
- Three columns, **101 mm** wide, which gives about 115 characters per line at 1.25 mm.
- **Column 1 runs the full height,** down to 3 mm above the frame.
- **Columns 2 and 3 are balanced** to a common bottom line. The generator finds the highest line at which all the notes still fit (`col_bottoms()`, `fits()`).
- The column rule between columns 1 and 2 runs full height.

**Typical details band:**
- Sits under columns 2–3, from the left edge of column 2 to the right edge of the note area (about 207 mm wide).
- Its top rule is 2.5 mm above the band title, which is 5 mm below the bottom of columns 2–3.
- Three panels with 6 mm gaps, width fractions `BAND = [(det_cover, 0.40), (det_hooks, 0.27), (det_laps, 0.33)]`.
- The band is about 60 mm tall. Everything in it must stay ≥ 3 mm above the frame, including dimension lines.

**Title strip:** the standard one.
- Drawing title: "GENERAL NOTES / STRUCTURAL CONCRETE".
- Scale: N.T.S.
- Key plan: "NOT APPLICABLE".
- Status stamp: as for the set.

## 4. Writing the notes

### 4.1 Structure

- **Section headers:** `n. TITLE`, bold 1.75, in the order of `GENERAL_NOTES_STRUCTURAL_CONCRETE.md`:
  - 1 General, 2 Design basis and standards, 3 Concrete, 4 Testing and acceptance;
  - 5 Reinforcement, 6 Development and splices, 7 Concrete cover, 8 Formwork, shoring and embedded items;
  - 9 Placing and compaction, 10 Curing, 11 Joints, 12 Finishing and repair;
  - 13 Inspection and records, then Abbreviations.
- **Notes:** `n.m` number at the column edge; text at the hanging indent (5.0), wrapped to the column.
- **Sub-items:** `(a) (b) (c)` one indent further (`level=1`).
- **Tables:** follow the note that introduces them, inside the same section.

### 4.2 Wording

- **Case:** all upper case. Only these stay lower case: units (mm, m, kg/m³, MPa, ksc) and symbols (f'c, fy, db, w/b, Sn).
- **One requirement per sentence.** Use "SHALL" for obligations and imperative verbs for site actions ("CURE…", "STAGGER…").
- **Numbers:** always with units and a comparison sign, e.g. `≥ 7 DAYS`, `≤ 1.5 m`, `±10 mm`.
- **Cite the source at the end** of each note, in square brackets, in this order:
  1. **EIT 011008** (design standard, EIT 011008-21);
  2. **EIT 011014** (materials and construction, EIT 011014-19);
  3. DPT, ACI or MIN. REG. only where both EIT standards are silent.
  - Format: `[EIT 011008 7.7.1; EIT 011014 2.5.1.5, T2.21]`.
  - Where the two EIT standards give different values, the note states the stricter one and cites both.
  - Use `T` for a table and `EQ.` for an equation.
- **Office values** (not in EIT) cite ACI, or no source if they are pure office practice. Keep them few. The office items are listed in `GENERAL_NOTES_STRUCTURAL_CONCRETE.md`.
- **Characters:**
  - **Allowed** (verified in the plotted PDF): `≥ ≤ ± ° ² ³ × Ø · – − ≈ α`.
  - **Not available in Arial Narrow, so don't use them:** Thai script, superscript minus `⁻`, subscripts `₄`, `√`.
  - Write `Cl`, `SO4` and `f'c + 1.65 Sn`.
- **Never type Thai** on a sheet. Write the standard number (`EIT 011014-19`), not `วสท.`.

### 4.3 What must always be on a concrete general-notes sheet

1. The governing standards: design, materials and construction, drafting, and TIS.
2. The **concrete schedule**: f'c (cylinder, 28 d) in ksc and MPa, max. w/b, slump and max. aggregate per element.
3. Cement, aggregates, water, admixtures and chloride limits.
4. Ready-mix rules: time limit, **no water on site**, delivery ticket.
5. Sampling rate and **acceptance criteria**; the non-conformance procedure.
6. Bar grades and TIS; no heating or re-bending; the **hooks and bends table**.
7. Fixing, spacers and placing tolerances.
8. The **lap and anchorage table** (tension, tension top, compression, standard hook ldh) and the splice rules: class A/B, stagger, no laps > DB36, 1.25 fy, approval.
9. **Column ties** (tie size by bar size, spacing), shrinkage steel, structural integrity.
10. The **cover table by structural element** (EIT 011008 7.7.1), and **separately, as a recommendation**, the environment-based cover (EIT 011014 α·c0 with corrosion-risk c0) and fire cover.
11. Sulfate classes (EIT 011008 T5.4) and embedded-pipe limits (EIT 011008 6.3).
12. Formwork loads, deflection, chamfers; the **form-removal table**; reshoring; the **tolerance table**.
13. Placing (free fall, rate, vibration), curing periods, construction joints, column vs floor concrete.
14. Finishing and repair; inspection hold points; records.
15. **Rev B:** project design data. Seismic: zone, Ie, category, systems with R / Ω0 / Cd, site class, S<sub>DS</sub> / S<sub>D1</sub>, analysis, seismic-system members. Wind: speed and return period. **Design loads:** live by use and roof, superimposed dead, partitions, live-load reduction, special loads.
16. **Rev B:** straight ld and compression ldc; bar supports (blocks, chairs); out-to-out bar dimensions.
17. **Rev B:** foundations and piles (soil report, bearing or pile data, pile tests, tolerances, heads and embedment, lean concrete, dewatering, fill); anchor bolts and grout; joint-layout submittal.
18. **Rev B:** abbreviations for rebar positions and call-outs, and every symbol used on the detail sheets.

## 5. Tables

| Property | Rule |
|---|---|
| Title | Bold 1.25, above the table, pitch 2.08, then 0.375 gap |
| Outer top rule, header rule, bottom rule | `S-TTLB` 0.35 black |
| Inner row rules, all column rules | `S-TTLB-THIN` 0.18 grey |
| Header row | Bold 1.25, same horizontal alignment as its column |
| **Vertical alignment** | **Every cell is centred on its row's centre line.** Text uses AutoCAD MIDDLE alignment (middle of the cap height). A wrapped cell is centred as a block, its lines 2.08 apart |
| **Horizontal alignment** | One letter per column (`align=`):<br>• **`C` middle-centre** for numbers, sizes and values (cover, lap lengths, strengths, w/b, slump, tie sizes, tolerances);<br>• **`L` middle-left** (inset 0.75) for descriptions (element, condition, item) |
| Cell text | 1.25. Cells wrap at the column width − 1.4; the row grows by 2.08 per extra line |
| Column widths | Given as fractions of the column width, summing to 1.0 |
| Note under the table | 1.25 text, 1.0 below the bottom rule, ending with the citation |
| Splitting | A table is never split across columns; it moves whole to the next column |
| Number (Rev B) | "TABLE n - NAME", numbered in flow order; a title must fit one column (the build warns) |

**Table sources.** Never type the computed values by hand:

| Table | Source in `build_gn.py` |
|---|---|
| Concrete schedule | Literal rows in `content()`: edit per project |
| Concrete schedule alignment | `LCCCC` |
| Sulfate exposure | Literal rows (EIT 011008 T5.4), `LCCLC` |
| Hooks and bends | Literal rows (EIT 011008 7.1, 7.2, T7.1), `LCC` |
| Column ties | Literal rows (EIT 011008 7.10.5), `CC` |
| Lap and anchorage | Computed with `FC_LAP = 23.5` MPa (240 ksc), `FY_LAP = 390`, rounded **up** to 50 mm, alignment `L` + `C…`:<br>• `ld_simple(db)`: straight tension ld (Rev B row);<br>• `lap_len(db, top)`: class B 1.3 ld, with ld per **EIT 011008 12.2.2** (2.1 for ≤ 20 mm, 1.7 for ≥ 22 mm; ψt = 1.3 for top bars);<br>• `ldc(db)`: 0.24 fy / √f'c db ≥ 0.043 fy db ≥ 200 (Rev B row, EIT 12.3.2);<br>• `lap_comp(db)`: 0.071 fy db ≥ 300;<br>• `ldh(db)`: fy / (4.2 √f'c) db ≥ 8 db ≥ 150 |
| Cover by element | `COVER_ELEM` literal rows (EIT 011008 7.7.1), `LLCC` |
| Recommended cover (environment) | `cov(c0, α)` over `COVER_ENV` (EIT 011014 T2.23 c0 50 / 65), c = α·c0 rounded **up** to 5 mm, α = 1.0 when c0 ≤ 20; `LCCC` |
| Form removal | Literal rows (EIT 011014 T10.1 / T10.2), `LCC` |
| Tolerances | Literal rows (EIT 011014 10.7), `LC` |

## 6. Typical details band (Rev A; Rev B uses column figures, see §0)

**Each panel contains:**
- a **view title** via `ptitle()`: bold 1.75 on an underline, with "SCALE 1:10" or "N.T.S." below at 1.25;
- the drawing;
- a short explanatory note (1.25) ending with its citation.

**The three standard panels:**

| Panel | Content | Rules |
|---|---|---|
| **Typical cover – beam section** | 250 × 350 at **1:10**:<br>• stirrup RB9;<br>• 3-DB20 bottom, 2-DB16 top;<br>• dimensions `c`, 250, 350;<br>• two short notes to the right | See **stirrup rule** below.<br>Dots are true size.<br>Stirrup on `S-REBR-SEC` (0.35); dots on `S-REBR` |
| **Standard hooks** | Stacked, each with its label beside it:<br>• 90° main-bar hook (12 db);<br>• 180° hook (4 db ≥ 65);<br>• 135° stirrup with its four corner bars (6 db ≥ 75) | Bars on `S-REBR`, bends filleted; stirrup per the stirrup rule |
| **Typical lap splices – stagger** | Three bars with laps; lap dimension "LAP (TABLE 6)"; stagger "≥ 1.0 m CLEAR" | **Cranked laps** (office standard, 2026-09-30): the lapped bar runs 1.0 above the other over the lap, passes its end by 1.0, cranks back at 1:3 (`lap_crank`); no tie-wire strokes or end slashes; stagger dimension below the bars, clear of them |

Two panels were dropped when the notes grew: construction joints and column concrete through the floor. Their text stays in notes 11.1 and 11.3. `det_cj` / `det_colfloor` can be reinstated on a two-sheet set.

**Stirrup rule (all drawings):**
- Every stirrup corner is an arc **concentric with its corner bar** (radius = bar radius + half the stirrup diameter), so the bars sit in the bends.
- Both 135° hooks turn around the **same corner bar** and run into the core at 45°, one on each side of the bar.
- Hook length ≥ max(6 db, 75 mm).
- Use `stirrup(ps, tl, tr, br, bl, leg)`, where each corner is `(x, y, R)`.

**Dimensions in details:** the dimension style ×K from §2.1. Use `dim(..., text="…")` for symbolic or true values: paper-space dimensions measure paper mm, so the true value is typed.

Add or replace panels by writing `det_xxx(ps, x, y, w)` and listing it in `band()`. Keep a panel's content inside its width `w`, and at least 8 mm above the frame.

## 7. Layout engine (how the generator places text; Rev B changes in §0)

- **Line by line.** Every line is its own TEXT entity, placed at a width measured from the Arial Narrow font files (fontTools, `text_w`). AutoCAD therefore never re-wraps the text, and the plot matches the layout exactly. **Do not use MTEXT** for the notes.
- **Flow.** `Flow` fills column 1 top-down, then column 2, then column 3:
  - A **header** moves to the next column unless the header and 3 lines fit below it.
  - A **note** never leaves a single line at a column foot; it may continue at the top of the next column.
  - **Tables and figures** move whole.
- **Balancing.** `Flow` takes one bottom line per column (`col_bottoms(yb)`): column 1 runs to the frame, and columns 2 to NCOL stop at `yb`. `fits(yb)` runs the flow without drawing. A binary search finds the highest `yb` at which everything fits, and the details band takes the space below `yb` under columns 2–3.
- **Overflow.** If the notes cannot fit even down to the frame, the last column is exceeded. Reduce the text, set `NCOL = 4`, or move tables to a second sheet (`…-1002`). **Never reduce K.**

## 8. Per-project use

1. Copy `jobs/general_notes/` into the job, or run it in place with a new output folder.
2. Edit `PROJ`: code, owner, project, location, office, date, stage, revision. Set the sheet number in `SHEETS`.
3. Edit the **concrete schedule** rows and, if f'c changes, `FC_LAP` (the lap table recomputes).
4. Delete notes that don't apply (e.g. seismic hooks, recycled aggregate, water-retaining). Add project notes in the right section, with their citations.
5. Build and plot **from PowerShell**:

```bash
python build_gn.py out
```
```bash
python plot_gn.py out
```

6. Check the printed A3 (§9).

## 9. Pitfalls met

| Problem | Cause | Fix |
|---|---|---|
| Thai text plots as boxes or garbage | Arial Narrow has no Thai glyphs | English only |
| `⁻`, `₄` show as `?` | Missing glyphs | Write `Cl`, `SO4` |
| The plot hangs at the file-name prompt | A space in the output path is read as Enter by the AutoCAD script | `plot_gn.py` quotes paths; keep it that way |
| Dimension text at 2.0 on the notes sheet | Base dimension style used | Use the ×K dimension style (`_gds`) set at the top of the notes engine |
| Table text touching the rules, or visually off-centre | Baseline-offset placement | MIDDLE-aligned text on the row centre line (`TA.MIDDLE_LEFT` / `TA.MIDDLE_CENTER`); values in centred columns |
| Beam detail dimension on the frame | Band shorter than the detail | Keep the typical beam at 250 × 350 at 1:10, or reduce the notes |
| Lap values differ from ACI tables | EIT 011008 12.2.2 puts 20 mm in the small-bar group (2.1), ACI uses 1.7 for bars > 19 mm | Follow EIT: DB20 tension lap 1000, not 1250 |
| Refactor deleted detail functions | Deleting a code block by start/end markers | Grep the `def` list after every scripted edit |
| Header alone at a column foot, its table in the next column (Rev B, user) | The header reserved only 3 text lines | Keep-with-next: the next item places the header (§0) |
| A nearly empty last sheet with only the details band | The band needed its own height, but the notes filled two sheets | Details as column figures in the flow (§0) |
| Detail text overlapped at 2.0 mm | Fixed y offsets designed for 1.25 text | Place text in measured sequence (`note_lines` returns the y below) |
| Revision description ran into the date column | Longer than about 30 characters at 2.0 | Shorten, e.g. "TEXT 2.0 mm, 3 SHEETS" |
| Table numbers shifted and broke "1002 TABLE 6" on the detail sheets | A new table inserted before them | Extend an existing table or append; `TABLE_REFS` warns |
| A general rule contradicted a detail ("stagger all laps" vs column laps at one level) | Blanket wording | Write the exception into the note: "U.N.O. …" |
