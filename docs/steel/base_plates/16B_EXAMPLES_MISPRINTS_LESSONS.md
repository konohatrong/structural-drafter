# 16B Misprints in DG1 and lessons from the examples

## Misprints found [REC]

1. **Ex. 4.2 ASD:** prints "430 kips ≤ 400 kips o.k.". Pp/Ω = 0.85 × 3 × 360 × √(518/360) / 2.50 = **440 kips**, so 430 ≤ 440 passes; "400" is a misprint.
2. **Ex. 4.9** refers to "the W10×45 column considered in Example 4.6"; the W10×45 is in **Example 4.5** (4.6 is a W12×96).
3. **§3.5.3** pairs the rod shear stresses with the thread conditions the wrong way round and gives φ 0.55 / Ω 2.75, while the examples use φ 0.75 (15).
4. **Table 2.3** prints a 3¼ in. hole for both 2 and 2½ in. rods (04).
5. **Ex. 4.7:** the 1½ in. trial edge distance is too small for the 2 5/16 in. hole and is raised to 2¼ in. Set the edge distance from the hole size first (13).

Like the stair notes (DG34): **recompute the examples; don't copy them.**

## Lessons [DG + REC]

- For gravity columns, **bearing and plate thickness** govern, and **n** often governs over m. Make m ≈ n.
- Rods on **piers** almost always need **lap development with the pier bars**: plain-concrete breakout fails.
- **Hooks** are weak in tension.
- Shear in rods needs **welded washers**, and large edge distances or reinforcement.
- The examples use small edge distances for clarity. Check real details against 04.
