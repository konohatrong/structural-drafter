# 05 Calculation

Outputs of the design calcs (`04 Code\calc\`): JSON and CSV results, check sheets (PDF/PNG), spreadsheets and hand
checks.

- Name an output after the check and the model revision it used: `pile_check_r40.json`, `pilecaps_r40.pdf`.
- Hand calcs and spreadsheets: `YYYYMMDD - <what>.xlsx`, with the model revision written on the sheet.
- The drawings and the calculation note read their numbers from these outputs; they never retype them.
- A check that fails is reported to the engineer with the options (`STATUS.md` §0); the redesign is the engineer's
  decision.
