# 07 Review

Internal review prints and what came back.

- Print name: `YYYYMMDD - {{CODE}}-ST <set> <rev> - <what>.pdf`, internal revisions A1, A2 … before the first
  submission, B1, B2 … after it (EIT Table 4.4). For example `20261009 - {{CODE}}-ST foundation A1 - S-101 S-303.pdf`.
- The returned markup goes into `markups\` with the same name plus ` - markup`.
- Each markup comment is fixed in the job; a comment that is a general rule is also written into the toolkit
  (`{{DRAFTER}}\docs`, AGENTS.md §3). Close the review in the `STATUS.md` log.
- Check sheets for the engineer (pile check, joint check) are prints too: they go here, their data stays in
  `05 Calculation`.
