# 09 Publish

Official issues only (the office "Transfer out"). One folder per issue, frozen once sent:

```
YYYYMMDD - <set> Rev <R> - <purpose>\
    PDF\            the signed or issued PDFs
    CAD\            DWG/DXF when they are part of the issue
    TRANSMITTAL.md  to whom, what, why, the basis (model revision, inputs of DD/MM/YYYY)
```

- Revision codes per EIT Table 4.4: A, B, C … submissions; 00 tender; 01, 02 … after tender.
- Add a row per sheet to `ISSUE_REGISTER.csv` the same day.
- **Never edit, replace or delete an issued folder.** A correction is a new issue with a new revision.
- An issue is the engineer's decision: prepare it, then ask before sending.
