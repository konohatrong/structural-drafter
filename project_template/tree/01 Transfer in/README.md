# 01 Transfer in

Everything received from others: architectural and MEP drawings, survey, soil report, client comments, markups from
outside the office.

- One folder per receipt: `YYYYMMDD - <from> - <what>` (for example `20261006 - AR - Tender set R3`).
- Add a row to `RECEIVED.md` the same day, and say what it supersedes.
- **Never edit anything here.** Convert or clean a copy in `06 CAD\xref` or `06 CAD\working` (DWG to DXF through
  the Core Console, for example) and name the source file in that folder.
- Thai text in received PDFs often does not extract: render the pages and read them as images.
